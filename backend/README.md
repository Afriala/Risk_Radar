# RiskRadar - Backend API
Cybersecurity Risk Management API (Node.js + Express)

## Module 1: User Management & Access Control
- User Registration & Authentication (JWT + Bcrypt)
- User Profile & Security Credentials
- Secure Session & Logout Handling
- Role-Based Access Control (Admin, Analyst, Executive, Auditor)

## Scripts
- `npm run dev`: Start local development server with nodemon
- `npm start`: Start production server
