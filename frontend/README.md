# RiskRadar - Frontend
Cybersecurity Risk Management UI (React + Vite + Tailwind CSS)

## Module 1: User Management & Access Control
- User Registration & Authentication UI
- User Profile & Security Settings (Password, MFA)
- Role-Based Route Protection (Admin, Analyst, Executive, Auditor)

## Scripts
- `npm run dev`: Start local development server (http://localhost:5173)
- `npm run build`: Build production assets for Vercel
